## Sobre a UC
Disciplina paralela à Lógica de Programação, com foco na sintaxe real da linguagem Python. Boa parte dos conceitos (variáveis, seleção, operadores lógicos) já foram trabalhados em Lógica — aqui o objetivo é aplicá-los numa linguagem de verdade.
